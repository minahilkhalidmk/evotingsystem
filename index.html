How fundamental C++ OOP paradigms are structured and executed inside `Main Code.cpp`.

Encapsulation

Private data members (`cnic`, `password`, `voteCount`) protected behind public accessor and mutator methods.

Inheritance

Polymorphism

Abstraction

Main Code.cpp — Abstract User & Derived Classes 
class User { // Abstract Base Class
protected:
    std::string cnic;
    std::string password;
    std::string name;
public:
    virtual ~User() {}
    virtual std::string getRole() const = 0; // Pure Virtual Abstraction
};

class Voter : public User { // Derived Class (Inheritance)
private:
    bool hasVoted;
    int votedCandidateId;
public:
    std::string getRole() const override { return "Voter"; } // Polymorphic Override
};
